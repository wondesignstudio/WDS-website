## 운영 원칙

1. 고객명, 로고, 프로젝트 화면, 역할과 성과는 근거와 공개 승인이 확인된 항목만 게시합니다.
2. 실제 프로젝트 콘텐츠와 이미지 비율을 확인하기 전에 최종 레이아웃을 고정하지 않습니다.
3. 승인된 시각 콘셉트와 보이는 문구를 구현 기준으로 잠급니다.
4. Contact는 화면이 아니라 저장, 알림, 실패 복구까지 포함한 운영 기능으로 검증합니다.
5. 코드 검사만으로 완료하지 않고 실제 브라우저에서 데스크톱, 태블릿과 모바일을 검수합니다.
6. 결정 변경은 관련 문서와 완료 기준에 함께 반영합니다.

## 상태 표기

- `NOT_STARTED`: 착수 전
- `IN_PROGRESS`: 작업 중
- `BLOCKED`: 외부 입력 또는 결정 필요
- `READY_FOR_REVIEW`: 검토 가능
- `APPROVED`: 승인 완료
- `NOT_APPLICABLE`: 적용 대상 아님
