# WDS 웹사이트 공개 승인·사실 검증 매트릭스

> 문서 상태: Phase 0 초안  
> 기준 기획서: [`../source/WDS_Website_Planning_v0.1.md`](../source/WDS_Website_Planning_v0.1.md)  
> 목적: 웹사이트에 노출되는 프로젝트, 고객명, 로고, 화면, 추천사, 성과 수치, 브랜드 자산의 공개 권리와 사실성을 출시 전에 추적하고 승인한다.

## 1. 운영 원칙

- 기획서에 적혀 있다는 사실만으로 외부 공개 권리나 사실 검증이 완료된 것으로 보지 않는다.
- 공개되는 항목에는 고유 자산 ID를 부여하고, 원본·근거·승인 기록을 해당 ID로 연결한다.
- 고객사와 직접 계약한 프로젝트인지, 협력사·파트너를 통해 간접 수행한 프로젝트인지 반드시 구분한다.
- 이미지 사용 권리와 이미지 안에 보이는 상표, 인물, 개인정보, 고객 데이터, 제3자 콘텐츠의 권리를 각각 확인한다.
- 수행 범위, 출시 상태, 연도, 고객 평가, 성과 수치는 서로 분리해 검증한다.
- 서면 승인에는 승인 대상, 사용 매체(공식 웹사이트·SNS·제안서 등), 허용 기간, 수정 허용 범위가 드러나야 한다.
- 조건부 승인은 조건이 실제로 충족되고 증빙이 연결되기 전까지 `GO`가 아니다.
- 최종 결정이 `GO`인 항목만 Production 빌드와 Open Graph 이미지에 포함할 수 있다.

## 2. 상태 값과 판정 기준

### 자산·라이선스 상태

| 값 | 의미 |
|---|---|
| `미수집` | 원본 파일이나 라이선스 문서를 확보하지 못함 |
| `수집` | 원본 또는 문서를 확보했지만 검토 전 |
| `검토 중` | 소유권, 사용 범위, 제3자 권리를 확인 중 |
| `확인` | 웹사이트 공개에 필요한 권리와 의무를 확인함 |
| `제한부 확인` | 기간, 지역, 크레딧, 편집 금지 등 제한이 있음 |
| `사용 불가` | 권리 미확보, 반려 또는 제한 위반으로 공개할 수 없음 |

### 외부 승인 상태

| 값 | 의미 |
|---|---|
| `미요청` | 승인 요청 전 |
| `요청` | 승인 요청을 보냈으며 회신 대기 중 |
| `조건부 승인` | 수정 또는 제한 조건이 붙은 승인 |
| `승인` | 승인 대상과 범위가 명시된 서면 승인을 확보함 |
| `불필요-근거 있음` | 외부 승인이 불필요하며 그 판단 근거를 기록함 |
| `반려` | 공개 승인 거절 |
| `만료` | 승인 기간이 지났거나 철회됨 |

### 최종 공개 판정

| 값 | 의미 |
|---|---|
| `GO` | 권리, 사실, 승인, 제한 준수, 접근성 문구까지 모두 확인됨 |
| `CONDITIONAL` | 공개 전 충족해야 할 조건이 남아 있음. Production 노출 금지 |
| `NO-GO` | 필수 증빙 또는 승인이 없거나 사용 불가. Production 노출 금지 |

## 4. 증빙 기록 규칙

각 행의 승인 출처와 근거는 다음 형식으로 남긴다. 민감한 계약서 원본은 공개 저장소에 커밋하지 않고 접근 통제된 보관 위치의 문서 ID나 링크만 기록한다.

| 필드 | 기록 예시 |
|---|---|
| 원본 자산 | 파일 경로 또는 DAM 링크, 파일명, 버전, 해시 또는 최종 수정일 |
| 사실 근거 | 계약/SOW 문서 ID와 조항, 납품 확인서, 운영 URL, 분석 리포트의 페이지·셀 범위 |
| 승인 출처 | 이메일 thread URL, 전자결재 ID, 서명된 승인서 ID, 회의 후 서면 확인 링크 |
| 승인 범위 | 대상 자산 ID, 사이트 영역, 사용 매체, 편집 허용, 언어, 지역, 기간 |
| 승인자 | 성명, 소속, 직함, 해당 자산을 승인할 권한이 있는 이유 |
| 검토 이력 | 검토자, 검토일, 변경 내용, 이전 판정, 새 판정 |

파일이나 문구가 바뀌면 같은 자산 ID의 버전을 올리고 재검토한다. 승인 대상과 실제 배포본이 다르면 기존 승인은 무효로 보고 `NO-GO`로 되돌린다.

## 5. 승인 워크플로

1. **등록** — 게시 후보를 한 행에 하나씩 등록하고 자산 ID, 담당자, 사용 위치를 정한다.
2. **원본 수집** — 로고·이미지는 공식 원본을, 폰트는 실제 배포 파일과 라이선스를, 문구는 최신 원문을 수집한다.
3. **관계·역할 확인** — 계약서, SOW, 납품물로 고객·프로젝트 명칭과 WDS의 직접/파트너 관계 및 수행 범위를 확인한다.
4. **권리 검토** — 저작권, 상표, 초상권, 개인정보, 기밀정보, 제3자 콘텐츠, 편집·재배포 권한과 만료일을 확인한다.
5. **사실 검증** — 주장마다 1차 근거를 연결하고, 성과 수치는 정의·기간·비교 기준·계산식을 함께 검토한다.
6. **외부 승인** — 고객 또는 권리자가 자산 ID와 실제 게시 시안을 확인할 수 있게 요청하고 서면 회신을 보관한다.
7. **제한 반영** — 크레딧, 관계 표기, crop 금지, 게시 기간 등 조건을 디자인·콘텐츠·코드에 반영한다.
8. **접근성 검토** — 정보성 이미지에는 맥락과 목적을 설명하는 대체 텍스트를 작성한다. 장식 이미지는 빈 `alt` 적용 여부를 기록한다.
9. **사전 배포 대조** — Preview의 파일·문구·노출 위치가 승인본과 동일한지 자산 ID 기준으로 대조한다.
10. **최종 판정** — 담당자가 증빙을 연결하고 검토자가 `GO`로 바꾼 뒤, 출시 승인자가 전체 서명을 완료한다.
11. **출시 후 관리** — 승인 만료, 고객의 철회 요청, 로고 변경, 운영 화면 변경을 확인해 즉시 숨기거나 재승인한다.

## 6. 공개 차단 규칙

다음 중 하나라도 해당하면 해당 자산과 이를 포함한 섹션은 `NO-GO`다.

- 자산 ID, 담당자, 실제 원본 또는 사용 위치가 없다.
- 저작권·상표권·초상권·라이선스 소유자나 웹 게시 가능 범위를 확인하지 못했다.
- 고객명, 로고, 프로젝트 화면, 추천사에 필요한 서면 승인이 없거나 승인 대상이 모호하다.
- 직접 프로젝트와 파트너·협력사 프로젝트의 관계 및 WDS 역할이 확인되지 않았거나 오인 가능하게 표시되어 있다.
- 기획서 문구만 있고 계약, 납품물, 운영 URL, 고객 확인 등 1차 사실 근거가 없다.
- 성과 수치의 원본 데이터, 지표 정의, 측정 기간, 비교 기준 또는 계산식이 없다.
- 추천사가 원문과 의미상 다르거나 작성자·직함·실명 공개 범위에 대한 승인이 없다.
- 화면에 개인정보, 계정 정보, 내부 URL, 고객 데이터, 미공개 기능, 계약상 기밀 또는 승인되지 않은 제3자 콘텐츠가 보인다.
- 승인 조건, 로고 가이드, 필수 크레딧 또는 폰트 라이선스 의무가 실제 구현에 반영되지 않았다.
- 승인·라이선스가 만료되었거나 권리자가 철회·반려했다.
- Preview와 승인받은 파일·crop·문구·수치·노출 위치가 다르다.
- 정보성 이미지의 대체 텍스트가 없거나 이미지와 다른 내용을 주장한다.

차단된 항목을 임시 로고, 가짜 고객명, 추정 수치, 임의 추천사로 대체하지 않는다. 해당 항목 또는 섹션을 숨기고, 사실 검증과 승인을 완료한 뒤 다시 포함한다.

## 7. 출시 전 일괄 점검

- [ ] 모든 Production 노출 자산 ID가 이 문서에 존재한다.
- [ ] 모든 게시 행의 최종 판정이 `GO`다.
- [ ] Marketing Catnip, TimeAttack, Questboard의 고객명·연도·상태·수행 범위·직접/파트너 관계가 확인되었다.
- [ ] Selected Clients의 모든 로고가 개별 행으로 분리되고 고객별 승인을 받았다.
- [ ] 모든 프로젝트 이미지가 개별 행으로 분리되고 개인정보·기밀·제3자 자산 검수를 통과했다.
- [ ] 모노그램 원본과 WDS의 사용 권리를 확인했다.
- [ ] 실제 배포하는 SUIT 버전의 라이선스 원문과 준수 조치를 저장했다.
- [ ] 추천사와 성과 수치는 사용하지 않거나, 개별 원문·1차 근거·서면 승인을 연결했다.
- [ ] 제한 조건과 만료일을 코드·콘텐츠·운영 캘린더에 반영했다.
- [ ] Preview와 승인본의 파일, crop, 문구, 수치, 링크, 대체 텍스트가 일치한다.
- [ ] 모바일·데스크톱 및 OG 이미지에서 승인되지 않은 자산이 노출되지 않는다.
