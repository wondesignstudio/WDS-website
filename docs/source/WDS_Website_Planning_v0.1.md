# Won Design Studio 공식 웹사이트 기획서 v0.1

## 1. 프로젝트 개요

### 프로젝트명
Won Design Studio 공식 웹사이트 신규 구축

### 목적
원디자인스튜디오를 단순한 디자인 외주사나 소규모 제작사가 아니라, 기업의 중요한 디지털 프로젝트를 함께 수행하는 **Digital Experience Partner**로 인식시키는 공식 웹사이트를 구축합니다.

### 웹사이트의 역할
- 브랜드 포지셔닝 전달
- 대표 프로젝트와 수행 역량 증명
- 일하는 방식과 품질 기준 설명
- 프로젝트 상담 전환
- 장기적으로 리서치, 제품, 채용 콘텐츠를 축적하는 기반 마련

### 핵심 전환
**프로젝트 상담 신청**

### 보조 전환
- 프로젝트 상세 확인
- 웹사이트 진단 서비스 확인
- 회사와 업무 방식 이해

---

## 2. 목표 사용자

### 주요 사용자
- 기업의 사업기획팀
- 마케팅팀
- 브랜드팀
- 신사업팀
- 제품팀
- 개발팀
- 웹사이트 리뉴얼 또는 디지털 제품 구축을 담당하는 실무자와 의사결정자

### 사용자가 확인하려는 질문
1. 이 회사는 우리 사업을 이해할 수 있는가?
2. 디자인과 개발을 어디까지 맡길 수 있는가?
3. 실제로 어떤 프로젝트를 수행했는가?
4. 진행 과정과 커뮤니케이션은 안정적인가?
5. 출시 이후 운영과 개선도 가능한가?
6. 우리 규모의 프로젝트를 맡길 수 있는가?
7. 상담을 시작하려면 무엇을 준비해야 하는가?

## 3. 브랜드 메시지

### 포지셔닝
**Digital Experience Partner**

### 한 줄 설명

### 핵심 메시지
- 사업을 이해하고 시작합니다.

### 브랜드 신념

### 브랜드 에센스
> 깊이 이해하고, 끝까지 완성합니다.
> Understand Deeply. Deliver Completely.

## 6.6 Capabilities

### Headline
> 문제를 이해하는 일부터
> 출시 이후의 개선까지 연결합니다.

### Process
1. Diagnose
2. Design
3. Develop
4. Launch
5. Improve

### 내용
#### Diagnose
사업 메시지, 정보 구조, UX/UI, 기술과 운영 환경을 분석합니다.

#### Design
사업과 사용자가 만나는 방식을 콘텐츠, 화면, 인터랙션과 디자인 시스템으로 구체화합니다.

#### Develop
프론트엔드, 백엔드와 관리자 시스템을 프로젝트 범위에 맞춰 구현합니다.

#### Launch
디자인과 실제 구현 결과를 검수하고 반응형, 기능과 주요 오류를 확인한 뒤 출시합니다.

#### Improve
운영과 데이터를 바탕으로 다음 개선 과제를 제안합니다.

- Hero 제목 3~4줄 이내

- 복잡한 메타데이터 축약
- 프로젝트 이미지는 세로 흐름 권장
- 고정 CTA는 화면을 과도하게 가리지 않도록 함
