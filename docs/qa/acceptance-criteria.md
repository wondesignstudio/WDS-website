# WDS 웹사이트 완료 기준

## 사용 방법

이 문서는 구현과 출시의 필수 수용 기준입니다. 각 항목은 `PASS`, `FAIL`, `BLOCKED`, `NOT_APPLICABLE` 중 하나로 기록하고 근거 링크 또는 캡처 경로를 남깁니다. `필수` 항목이 `FAIL` 또는 근거 없는 `BLOCKED`이면 출시할 수 없습니다.

| 상태 | 의미 |
| --- | --- |
| `PASS` | 실제 환경에서 확인했고 근거가 있음 |
| `FAIL` | 기준을 충족하지 못함 |
| `BLOCKED` | 외부 입력이 필요하며 오너·기한·대체 처리가 기록됨 |
| `NOT_APPLICABLE` | 적용하지 않는 근거가 승인됨 |
