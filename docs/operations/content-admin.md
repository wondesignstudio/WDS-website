# 프로젝트·미디어·법적 문서 관리자 운영

## 1. 최초 적용

1. Supabase SQL Editor에서 `supabase/migrations/202607140001_content_admin.sql`을 실행합니다.
2. `portfolio_projects`, `media_assets`, `legal_documents` 테이블과 비공개 `wds-media` 버킷이 생성됐는지 확인합니다.
3. 기존 Google 관리자 허용 계정으로 `/admin`에 로그인합니다.
4. `/admin/projects`, `/admin/media`, `/admin/legal` 접근을 확인합니다.

현재 Preview: `https://wds-website-gl9q9e7l7-wondesign01-6115s-projects.vercel.app`

2026-07-14 기준 운영 관리자 Google 로그인, 기본 프로젝트 3건 조회, Questboard 공개 상세 페이지, 프로젝트별 이미지 업로드 폼과 상세 이야기 미리보기, 프로젝트 폼 이탈 방지 모달, 데스크톱 고정 사이드바와 모바일 접근성 드로어, 미디어·법적 문서 화면 접근, 데스크톱·모바일 14px 본문과 가로 오버플로 없음까지 확인했습니다. 관리자 이동 중에는 현재 화면을 유지하며 240ms 이상 지연될 때만 작은 진행 표시를 노출합니다. 실제 승인 자산 업로드와 법적 문서 발행은 공개할 운영본이 준비된 뒤 검증합니다.

## 2. 프로젝트

- `목록 공개`가 켜진 프로젝트만 `/work`와 홈페이지에 표시됩니다.
- 프로젝트 목록은 카드 갤러리와 테이블 보기로 전환할 수 있고, 새 등록은 `/admin/projects/new`에서 진행합니다.
- `상세 공개`는 목록 공개 상태에서만 켤 수 있습니다.
- 프로젝트 이미지는 각 프로젝트 편집 화면에서 바로 업로드·정렬·공개할 수 있고, `/admin/media`에서는 전체 자산을 함께 관리합니다.
- 새 프로젝트를 만들 때 대표 이미지 1개를 함께 등록할 수 있고, 저장 후 프로젝트 편집 화면에서 추가 이미지와 공개 순서를 관리합니다.
- 노출 순서는 1부터 시작하며 숫자가 작은 프로젝트가 먼저 표시됩니다. 신규 프로젝트는 현재 마지막 순서의 다음 번호가 기본값입니다.
- 기존 10·20·30 순서는 `supabase/migrations/202607140004_normalize_project_order.sql`을 한 번 적용해 1·2·3으로 정규화합니다.
- 상세 이야기 편집기는 소제목, 굵은 글씨, 목록과 링크를 지원하며 발행 전에 미리보기를 확인할 수 있습니다.
- 저장하지 않은 프로젝트 내용이 있으면 관리자 메뉴 이동 전에 확인 모달이 열리고, 새로고침·탭 닫기에는 브라우저 기본 경고가 표시됩니다.
- 프로젝트 목록의 `수정`으로 편집 화면에 들어가고, `삭제`는 확인 모달을 거친 뒤 연결된 이미지 정보와 비공개 파일을 함께 정리합니다.

## 3. 미디어

- 업로드 형식: JPG, PNG, WebP
- 새 미디어 등록은 목록과 분리된 `/admin/media/new`에서 진행합니다.
- 최대 용량: 파일당 10MB
- 프로젝트 이미지는 연결 프로젝트와 대체 텍스트가 필요합니다.
- 고객 로고는 고객사명과 대체 텍스트가 필요합니다.
- `승인` 상태의 자산만 공개할 수 있습니다.
- 파일은 비공개 Storage에 저장되며, 공개 API가 자산과 프로젝트의 게시 상태를 다시 확인한 뒤 짧은 유효기간의 URL을 발급합니다.
- 개별 미디어 삭제는 확인 모달을 거치며, Storage 파일 삭제를 확인한 뒤 DB 기록을 제거합니다. 어느 단계에서 실패했는지 화면에 안내하고 남은 단계를 재시도할 수 있습니다.

## 4. 법적 문서

1. 개인정보처리방침 또는 이용약관의 `초안 만들기`를 선택합니다.
2. 제목, 버전, 시행일, 소개 문구와 본문을 작성합니다.
3. `초안 저장` 후 공개 화면의 문구를 다시 검토합니다.
4. `새 버전 발행`을 선택하면 이전 공개 버전은 자동 보관되고 새 버전이 공개됩니다.

본문 표기 규칙:

- `##` 조항 제목
- `###` 하위 제목
- `-` 목록
- HTML은 실행하지 않고 일반 문자로 표시

이용약관은 최초 발행 전까지 공개 푸터와 sitemap에 노출되지 않습니다.

## 5. 게시 전 확인

- 이미지와 로고의 공개 권리·기간·편집 가능 여부
- 이미지 대체 텍스트와 캡션
- 프로젝트 고객사명, 역할, 성과 문구의 사실 여부
- 개인정보처리방침의 실제 처리 방식·연락처·시행일
- 이용약관의 계약 체결 조건과 지식재산권 문구
