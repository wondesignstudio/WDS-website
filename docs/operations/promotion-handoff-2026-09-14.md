## 이미지·로고 등록

1. 관리자 → 프로젝트 → 새 프로젝트 또는 수정에서 제목·요약·유형·수행 범위와 상세 본문을 작성한다.
2. 대표 이미지 및 추가 이미지를 업로드하고 대체 텍스트를 입력한다. 이미지 안에 고객 개인정보나 기밀이 없는지 확인한다.
3. 미디어의 승인 상태와 공개 상태를 설정한다. 프로젝트의 목록 공개와 상세 공개는 별도 설정이다.
4. 고객 로고는 미디어 → 미디어 추가에서 고객 로고 유형으로 등록하고 고객명·대체 텍스트·승인·공개 상태를 확인한다.
5. 공개 후 홈·Work·해당 상세를 시크릿 창에서 확인한다. 홈은 이미지가 있는 공개 프로젝트 순서대로 최대 3건을 노출한다.
6. 숨기려면 공개 상태를 해제한다. 영구 삭제는 복구되지 않으므로 공개 해제와 구분한다.

## 운영 체크

- 매 영업일: 관리자 문의 신규 건과 수신 메일을 확인하고 응답 후 상태를 갱신한다.
- 메일 문제: 관리자 운영 화면에서 재시도·보관기간 작업 결과를 확인한다. 다른 사람의 문의를 테스트 목적으로 재발송하지 않는다.
- 홍보 링크: 사이트 주소 또는 서비스별 페이지를 사용한다. UTM에는 캠페인명만 넣고 이메일·전화번호 등 개인정보를 넣지 않는다.
- 분석 동의를 거부한 방문은 GA4에 기록되지 않으므로 GA4 전환 수와 실제 문의 수가 같지 않을 수 있다.
- 법적 문서의 최종 발행과 고객 자산 공개 승인은 운영자 결정이다. Google Workspace는 필수 조건이 아니다.
