원디자인 스튜디오

미디어 업로더 개인정보 처리 안내

원디자인 스튜디오가 운영하는 미디어 업로더에 계정을 연결했을 때 적용되는 안내입니다.

접근하는 정보와 목적

Google 계정 소유자가 허용한 범위에서 YouTube 채널의 ID와 이름, 업로드한 영상의 ID·제목·공개 범위·처리 상태, 채널의 조회수와 시청 시간 등 집계 지표에 접근합니다. 이 정보는 대상 채널 확인, 승인된 영상의 업로드와 게시 확인, 중복 방지 및 채널 운영 분석에 사용합니다.

플랫폼으로 전송하는 정보

승인된 대상 플랫폼에 영상 파일, 지원되는 커버, 제목, 문구 및 공개 설정을 전송합니다. 업로더는 YouTube API 서비스를 사용합니다. Google 사용자 데이터에는 Google API 서비스 사용자 데이터 정책의 제한적 사용 요건을 따릅니다. Google 사용자 데이터를 판매하거나 광고 타기팅에 사용하지 않습니다.

보관과 접근

접근 토큰과 갱신 토큰은 운영용 Mac의 키체인에 저장합니다. 미디어 파일과 게시 기록은 작업 폴더에 보관하고, 연결된 내부 업무 공간에는 발행 계획이나 운영 지표가 동기화될 수 있습니다. 작업 폴더의 백업 및 동기화 여부는 운영 환경의 설정을 따릅니다.

권한 철회와 삭제

Google 계정의 연결 관리에서 언제든지 업로더의 접근 권한을 철회할 수 있습니다. 저장된 인증 정보와 운영 기록의 삭제 요청은 contact@wondesign.studio로 보내주세요. 운영자는 해당 계정을 확인해 키체인과 관리 중인 기록에서 요청 데이터를 삭제합니다. 이미 공개한 영상의 공개 범위 변경이나 삭제는 해당 플랫폼에서도 관리할 수 있습니다.
