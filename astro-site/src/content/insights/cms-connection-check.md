## CMS → Cloudflare 자동 배포 검증

검증 코드: WDS-PAGES-AUTO-20261023

이 글은 CMS에서 수정한 내용이 GitHub 커밋을 거쳐 Cloudflare Pages 미리보기 주소에 자동 반영되는지 확인하는 임시 글입니다. 실제 고객 사례나 정식 인사이트가 아닙니다.

검증 완료 후 공개를 끄고, 미리보기 목록과 상세 페이지에서도 제외되는지 확인합니다.
